# NR PRO BOT

Telegram VPN sales automation with automated configuration creation, payment flows, reseller tools, and a web admin panel.

## Installation

Run on a fresh Ubuntu 22.04/24.04 server as root:

```bash
curl -fsSL https://raw.githubusercontent.com/Alirezaftt12/NR-PRO-BOT/main/install.sh -o install.sh && bash install.sh
```

The installer is the canonical file in this repository. Review it before running. Never paste bot tokens or database credentials into public issues or commits.
